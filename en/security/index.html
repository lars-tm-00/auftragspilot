Security

How we protect your data and your number.

Your agent works with real customer conversations. So it only gets the access you allow, and every connection can be revoked with one click.

Passwords

Passwords are stored only as a salted scrypt hash, never in plain text.

Access keys

A key is shown once and then stored only as a SHA-256 hash. One key per agent, revocable any time in the app.

Three permission levels

Read, draft (everything outgoing waits for your approval) or write. You choose when you connect.

Sign-in for agents

OAuth 2.1 with PKCE (S256). Your agent opens a browser window, you sign in and click “Allow”. No key to copy.

Approval page

The page where you allow an agent cannot be embedded in other websites, so nobody can trick you into a click.

Short lifetimes

One-click setup links are valid for 2 hours. E-mail setup codes are valid for 30 minutes with at most 5 tries.

Separate accounts

Every key only sees its own account, never other customers' data.

Official WhatsApp connection

WhatsApp runs only over Meta's official WhatsApp Business Platform. No WhatsApp Web or QR code tricks, so no ban risk from unofficial automation.

Opt-out

When a contact writes STOP, we respect it permanently. That person gets no more messages.

Handover to a person

When a person takes over a conversation, the agent stops writing in that chat until it is handed back.

Protection against injected instructions

Customer messages that look like instructions to an AI are flagged as suspicious and passed to agents as untrusted customer text. The built-in AI does not follow them.

No double sends

With an idempotency key a message is sent only once, even if a request is retried.
